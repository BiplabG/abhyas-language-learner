Optional: sync your lists, words, and practice history across devices that share a private token. The newer version replaces the older one; changes are not merged. Reminder preferences stay on each device.

First run the latest supabase/setup.sql in your project's SQL Editor. Enter the same sync token on every device. The token is the private credential for this collection.

Generate a cryptographically random token, save it in a password manager, and reuse it on other devices. Supabase stores only its SHA-256 hash. Anyone with the token can read and replace this sync data. Never enter a service-role or secret key.
